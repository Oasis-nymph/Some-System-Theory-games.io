背景：为什么需要 Attention？

RNN 必须按顺序逐词处理（ht 依赖 ht-1），无法并行、长距离依赖弱。Attention 一步直接连接任意两个词，路径长度 O(1)。论文 Section 4 对比了三种架构（Table 1）。

Q、K、V 是什么？

输入 X ∈ Rn×d 分别乘以三组可学习投影矩阵 WQ, WK, WV 得到 Query、Key、Value。
Query："我想查什么"
Key："我有什么标签"
Value："我的实际内容"
（论文 Section 3.2）

为什么除以 √dk ？

假设 q,k 各分量独立且 Var=1，则 Var(q·k)=dk。dk=8 时内积标准差约 2.8，不缩放直接送 softmax → 接近 one-hot → 梯度消失。除以 √dk 将方差归一化到 1。论文 Section 3.2.1 尾注解释了这一点。

多头注意力（Section 3.2.2）

单头只能捕捉一种"关注模式"。h=4 个并行头各自在低维子空间 R8 中独立计算 Attention，最后拼接回 R32。
Head 0：恒等投影（语义头）
Head 1–3：随机高斯投影
下方色条可对比四头不同模式。

如何阅读热力图？

每行 = 一个 Query（"谁在看"）
每列 = 一个 Key（"被谁看"）
颜色越亮 = 注意力权重越高。
每行权重之和 = 1（概率分布）。
悬停单元格查看精确数值。
